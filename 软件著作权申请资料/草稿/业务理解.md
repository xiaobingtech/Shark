# 业务理解

- 软件名称：Shark
- 产品定位：基于 HarmonyOS 的远程推送通知客户端软件，通过 HTTP URL 即可向手机实时发送推送通知，兼容 Bark 服务端协议，支持自建私有推送服务器
- 面向领域 / 行业：移动应用软件 / 开发者工具与物联网通知
- 核心价值：用户只要通过浏览器、脚本或任何能发起 HTTP 请求的工具访问一条推送地址，就能把消息实时送达手机通知栏，无需开发原生推送集成，也无需在手机端注册任何第三方账号，开箱即用
- 证据文件：`业务理解证据.md`

## 目标用户

- 需要远程告警和消息推送的开发者（服务器监控、脚本执行结果、构建状态通知）
- 自动化与智能家居用户（NAS、Home Assistant、定时任务、爬虫通知）
- 需要把消息推送到手机的个人用户（备忘提醒、订阅信息）
- 希望自建推送服务、注重数据自主性的技术用户

## 主要业务功能

- 设备注册与推送地址生成
- 五种推送通知样式
- 多服务器管理与私有服务器接入
- 推送历史消息记录与管理
- 内置推送铃声库
- 应用设置与信息查看
- 应用内购买捐赠
- 应用更新检测与隐私合规

## 功能说明

- 设备注册与推送地址生成：首次使用点击“注册设备”，应用获取华为推送令牌并注册到推送服务器，服务器返回设备密钥，自动生成专属推送地址；地址由服务器地址、设备密钥、推送标题和内容组成。
- 五种推送通知样式：服务器主页提供普通推送、推送铃声、多行文本样式、通知角标、通知大图标五种样式卡片，每种卡片展示对应的推送地址，支持一键复制和浏览器打开测试。
- 多服务器管理与私有服务器接入：应用内置默认推送服务器（https://shark.xiaobingkj.com），用户可添加自建的私有服务器（输入地址或扫码），在服务器列表中随时切换当前服务器，并查看各服务器设备注册状态。
- 推送历史消息记录与管理：收到推送后自动保存标题、正文、时间、图片和样式信息，历史消息页按时间倒序展示，支持左滑删除并二次确认；可一键导出全部历史记录为 JSON 分享。
- 内置推送铃声库：内置 32 种系统通知铃声，用户可逐条试听，点击即可把铃声名称复制到剪贴板，用于在推送地址中指定铃声参数。
- 应用设置与信息查看：设置页提供默认保存开关（决定未指定归档参数的推送是否保存历史）、设备令牌复制、GitHub Actions 构建溯源信息查看，以及常见问题、使用文档、开源项目、应用评分、更多应用和关于页面入口。
- 应用内购买捐赠：集成华为应用内支付（IAP），提供“请我喝一杯奶茶”小额捐赠商品，购买流程包含商品查询、下单、支付、订单核验和完成购买。
- 应用更新检测与隐私合规：启动时通过华为应用市场检测更新并提示；首次进入主界面时请求隐私合规授权，遵循个人信息保护要求。

## 典型操作流程

1. 首次使用：打开应用 → 在服务器页点击“注册设备” → 系统弹窗允许发送通知 → 应用获取推送令牌并完成服务器注册 → 页面显示推送地址卡片 → 复制推送地址
2. 日常推送：在任意设备用浏览器、命令行或脚本访问推送地址 → 手机通知栏立即收到推送通知 → 点击通知进入应用历史消息页查看详情
3. 定制推送：在服务器页修改推送标题、内容、铃声、角标、图片等参数 → 应用实时拼接新的推送地址 → 复制或打开地址完成定制推送
4. 多服务器使用：进入“添加私有服务器”输入自建服务器地址或扫码 → 应用自动注册 → 保存后返回服务器列表 → 点选服务器完成切换
5. 历史管理：切到历史消息标签 → 浏览推送记录 → 左滑条目删除（弹窗确认） → 或在设置页导出全部历史为 JSON
6. 选铃声：服务器页点“查看所有铃声” → 试听铃声 → 点击复制铃声名 → 回到服务器页粘贴到推送地址

## 操作手册页面/流程模块

1. 首次启动与设备注册：启动软件后自动进入主界面“服务器”标签，页面中央显示“注册设备”圆形按钮。
   - 使用场景：用户第一次打开软件，需要先把当前设备登记到推送服务器，获得设备密钥后才能生成推送地址并接收推送。
   - 操作要点：打开软件进入服务器标签页；点击“注册设备”按钮；系统弹出通知权限请求时点击允许；等待注册完成，页面由按钮状态切换为五种推送样式卡片
2. 生成与测试普通推送：服务器主页第一张“推送标题”卡片。
   - 使用场景：用户想把一句标题和一段正文推送到手机时，在服务器主页填写推送标题和推送内容，生成推送地址后发送。
   - 操作要点：在卡片中修改推送标题和推送内容；观察卡片下方推送地址随输入实时更新；点击复制图标把地址复制到剪贴板；在浏览器、命令行或任意支持 HTTP 请求的工具中访问该地址，触发推送
3. 定制推送铃声、多行文本、角标与大图标：服务器主页的“推送铃声”“多行文本样式”“通知角标”“通知大图标”四张卡片，以及铃声卡片中的“查看所有铃声”入口。
   - 使用场景：用户需要通知更醒目或信息量更大时，可选用带铃声的推送提醒，或一次推送多行文本内容，或附带图片与角标数字。
   - 操作要点：在铃声卡片中填写铃声名称（或先进入铃声列表试听并复制铃声名）；在多行文本卡片中填写以竖线分隔的多行内容，生成 style=3 样式的推送地址；在角标卡片中设置角标增加数或设定数，生成 badge 参数的推送地址；在大图标卡片中填写图片链接，生成 image 参数的推送地址
4. 服务器列表与切换：服务器主页右上角的服务器列表图标。
   - 使用场景：用户添加了多个私有服务器后，需要确认当前使用哪个服务器，或切换到另一台服务器接收推送。
   - 操作要点：点击服务器主页右上角服务器列表图标；浏览服务器列表查看各服务器地址与注册状态；点击目标服务器条目完成切换；弹层关闭，服务器主页标题更新为所选服务器地址
5. 添加私有服务器：服务器主页右上角添加图标（加号），或菜单中的“添加”入口。
   - 使用场景：用户自行部署了推送服务端（如基于开源 Bark 服务端）时，需要把服务器地址登记到软件，并在该服务器上注册当前设备。
   - 操作要点：点击添加图标进入“添加私有服务器”页面；在输入框填写服务器地址，或点击扫码图标扫描服务器配置二维码；点击右上角“保存”；应用校验地址并自动完成设备登记
6. 铃声列表试听与复制：服务器主页“推送铃声”卡片中的“查看所有铃声”链接。
   - 使用场景：用户想给推送设置不同铃声时，先进入铃声列表试听并获取铃声名称，再回到服务器主页填写。
   - 操作要点：点击“查看所有铃声”进入铃声列表页；点击任一铃声条目，应用播放该铃声；铃声名称自动复制到剪贴板并提示“复制成功”；返回服务器主页把铃声名称填入推送铃声输入区
7. 历史消息查看与删除：主界面底部“历史消息”标签页；收到推送后点击通知也会自动跳转到该页。
   - 使用场景：用户错过通知或需要回看某条推送内容时，在历史消息页查看；不再需要时删除对应记录。
   - 操作要点：切换到历史消息标签页浏览推送记录；在目标条目上向左滑动；点击红色删除按钮；在弹出的确认对话框中点击“删除”完成删除，或点击“取消”返回
8. 历史消息导出：设置页“历史消息”分组中的“导出”条目，该条目右侧同时显示当前已保存的消息条数。
   - 使用场景：用户需要备份推送记录、把记录交给其他工具整理，或在更换设备前留档时，在设置页执行导出；导出内容包含每一条推送的标题、正文、发送时间、图片与样式信息。
   - 操作要点：进入设置页，在“历史消息”分组中找到“导出”条目；查看条目右侧的消息条数，确认要导出的记录范围；点击“导出”条目；系统弹出分享面板，在面板中选择目标应用（如文件管理、备忘录、即时通讯工具）
9. 设置项与信息查看：主界面底部“设置”标签页。
   - 使用场景：用户需要调整推送是否默认保存、查看设备令牌、确认版本构建来源或访问应用相关入口时使用。
   - 操作要点：切换“默认保存”开关决定未指定归档参数的推送是否保存历史；点击 Device Token 条目复制推送令牌；点击 Github Run Id 查看当前版本的构建记录；点击常见问题、使用文档、开源项目等条目打开对应网页
10. 关于页面：设置页“关于我们”条目，点击后从屏幕底部弹出“关于”窗口。
   - 使用场景：用户想了解软件版本归属、关注作者微信公众号或核实备案信息时进入；新用户也常在首次使用后从这里查看开发者信息。
   - 操作要点：在设置页点击“关于我们”条目；从屏幕底部弹出“关于”窗口，查看应用图标、软件名称与版权信息；点击公众号文字，公众号名称自动复制到剪贴板；点击备案号，系统浏览器打开工信部备案查询页面

## 申请表建议口径

- 开发目的：为 HarmonyOS 用户提供便捷、稳定、可私有化部署的 URL 远程推送通知工具
- 软件的主要功能：Shark 是一款面向 HarmonyOS 平台的远程推送通知客户端。软件以“一条 URL 触发一条通知”为核心交互模型，用户无需安装推送服务端软件、无需注册第三方账号，即可把任意消息实时推送到手机。首次使用时，用户点击“注册设备”，软件通过华为推送服务（Push Kit）获取设备推送令牌，并调用推送服务器的注册接口完成设备登记，服务器返回设备密钥后自动生成专属推送地址。服务器主页以卡片形式展示五种通知样式：普通推送、带铃声推送、多行文本样式、通知角标和大图标通知；每种卡片实时展示由服务器地址、设备密钥、推送标题、推送正文及样式参数拼接而成的推送地址，并提供复制与浏览器打开测试功能。软件支持多服务器管理：内置默认服务器，同时允许用户输入地址或扫描二维码添加自建的私有服务器（兼容 Bark 服务端协议），服务器列表可随时切换当前使用的服务器。收到推送后，软件自动将标题、正文、时间、图片与样式信息保存到本地历史记录，历史消息页按时间倒序展示，支持左滑删除并二次确认，也可在设置页一键导出全部历史记录为 JSON 文件分享。软件内置 32 种通知铃声供用户试听与复制，用于定制推送铃声。设置页提供默认保存开关、设备令牌查看、GitHub Actions 构建溯源、常见问题、使用文档、开源项目、应用评分、更多应用与关于等入口，并集成华为应用内购买实现小额捐赠，集成华为应用市场更新检测与隐私合规授权。
- 技术特点：基于HarmonyOS原生ArkTS开发，集成华为推送、通知、支付、扫码、分享等系统能力，支持多断点自适应布局
- 软件的技术特点选项：应用软件
- 软件分类：应用软件
